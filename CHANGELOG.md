# Changelog

## 0.1.0-alpha.1

First public Alpha, derived from a personal operations toolkit.

- External inventory/settings and non-destructive configuration initialization.
- Read-only defaults with explicit non-production write opt-in.
- Authenticated local task events separated from untrusted command output.
- Configurable diagnostic paths, trace scope and build settings.
- Credential-free synthetic demonstration.
- Task receipts, request deduplication, UNKNOWN lock retention and reconciliation.
- Production guards, bounded diagnostic recipes and pinned artifact verification.
- Isolated regressions, privacy validation, reproducible packaging and CI.

No live business assets or personal deployment configuration are distributed.
